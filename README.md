# TAPE - A Two-stage Adaptation Framework via Parameter Efficient Fine-tuning

This work is based on two foundation models :[ Masked Auto Encoder](https://openaccess.thecvf.com/content/CVPR2022/papers/He_Masked_Autoencoders_Are_Scalable_Vision_Learners_CVPR_2022_paper.pdf) and [RETFound](https://www.nature.com/articles/s41586-023-06555-x). Their pre-trained weights can be found in [link1](https://github.com/facebookresearch/mae) and[ link2](https://github.com/openmedlab/RETFound_MAE). We thank the authors for releasing the code.
